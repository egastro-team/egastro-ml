# єГастро — ML-модуль «Розумний кошик»

Market Basket Analysis (FP-Growth, асоціативні правила) для cross-sell рекомендацій за вмістом кошика.

## Структура

```
config.yaml          параметри моделі (пороги, K, вікно, holdout)
data/raw, processed  дані (не в git)
notebooks/           EDA і підбір порогів
src/egastro_ml/      код пакета
models/, reports/    артефакти (не в git)
tests/
```
